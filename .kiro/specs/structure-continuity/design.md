# 设计

## 1. 边界
新增独立的被动分析模块及审计模块，读取已归档的动态/结构证据。模拟模块、随机流和现有实验语义不变。只观察出生身份归属和组件成员，不能推断形态/功能保持。

## 2. 锚点切割谱系
在固定阶段与时刻，将所有存活身份作为父树的切割点。每个身份按出生顺序处理：若身份属于锚点集合则归属自己；否则继承父亲的切割归属，找不到则为空。这样同一锚点同时存活的父与子不会重复计算。它是明确选择的互斥归属惯例，不是完整的所有祖先关系。

对一个锚点组件，在每个后续时刻取得所有归属该组件成员的活身份。令D为其数量，S为原成员存活数，R为仍被代表的原身份数量，K为这些身份落入的当前组件数，U为这些组件中不归属该锚点组件的活身份数。

- D=0：extinct。
- K>1：fragmented；仍保留U，不隐藏同时混合。
- K=1且U>0：mixed。
- K=1、U=0、D=1：closed_singleton。
- K=1、U=0、D>=2：closed_multi。

每个区间保存五类状态计数及端点D/S/R/K/U。continuous_closed_multi要求锚点自身>=2且后续每一步closed_multi；complete_replacement要求端点D>0且S=0；primary为两者同时成立。endpoint_closed_after_break要求端点closed_multi但区间出现过其他状态，不声称必然为随机重连。R的保留量防止将单一祖先谱系接管误称全部锚点组织延续。

## 3. 实现与独立核对
生产模块一次构建锚点切割映射，对每个当前组件扫描身份，汇总归属的锚点组件计数。单个锚点最多256成员，20个来源，逐来源处理。

审计模块从原始 initial/steps 独立重建出生身份与父亲表，并核对 study009 每一步 interaction/final 身份。后续采用向后逐链查找第一个锚点身份、显式集合相交验证区间。不得调用生产根映射、分类或区间汇总函数。输入结构划分通过 study009 已归档哈希和独立审计绑定，不重定义组件。

## 4. 运行与预算
正式脚本从干净提交启动，绑定20来源网格、study009索引、协议与实现哈希，独占创建输出目录。先检查全部来源完整性，再逐来源输出和审计；失败保存进度，不覆盖重跑。

新输出上限1GiB，完整来源之间检查，允许单来源超出；运行软上限30分钟，完整来源之间检查，不并发重复启动。保持输入只读。来源结果含所有组件/锚点/时相/窗口的记录；汇总含空分母与来源覆盖。

## 5. 测量边界
此研究提供组件归属和成员替换基线，不衡量组织形状或功能，也不宣称闭合是生命的必要标准。世界级大组件、静止单元、选择性谱系接管可满足部分指标。必须保留锚点大小、成员保留率、闭合但未替换与替换但不闭合的区分。干预只有在这些描述明确之后单独登记。

## 6. 独立审查后的约束

当前模型后续活身份必须有最近锚点归属，否则失败。连续仅指同阶段记录快照，不排除时刻内部短暂单例或断裂。记录锚点大小/世界占据数、全世界组件标志和第一次完全替换时刻；全世界组件无外来成员条件具有平凡性。

科学参照：Montévil 与 Mossio（2020，doi:10.3389/fphys.2020.00611）将谱系和关系组织作为互补信息；Mossio 与 Moreno（2010，PMID:21162371）的组织闭合涉及因果约束。此处成员集合闭合不是上述因果组织闭合。
