# Study038方法决策：程序信息的位置与完整复制

本轮完成方法与来源可行性，未运行任何新世界。037的材料失败是提出假设的依据，不是证明编码位置单独造成失败。下一实验只比较完整的初始程序位置干预，不把材料、连接或能量路径拆称独立因果效应。

## 已确定的比较

[协议038](../../experiments/v4/study-038.md)固定四种异质程序：将原成员0/1的非零值1/2放在东、西、南、北槽，其余均0。E/W/S各20新案例，共60；N的20案例来自023，均一H的20案例来自019。五组共100案例共享20种子环境，不是100独立来源。所有新初态都明确是人为程序干预，不能把“0新增独立环境”写成“没有新初态变体”。

主要比较E−N、W−N、S−N，每个分母20且逐seed配对。均一是已有解释性参照，不是保证非组织的零模型。完整五组对均一表包含H−H的恒零自参照，不能作为额外比较证据。不同方向的几何/供能路径并不对称，不能解释为无关坐标旋转。

主指标保留原定义：每条轨迹自己的初始两成员模板、材料与完整程序精确平移匹配、完整材料组件、原祖系，双copy连续10步。模板不跨编码复用，不旋转，不额外要求同一对身份维持10步。全新副本作为附加指标，不能替换原主指标。

## 本轮排除的混淆

不进行“出现新副本后移除原成员”的续接。首次copy是否出现、何时出现都受编码影响；直接比较各编码入选后的成功率，会混合选择资格、剩余时间与续接机制。038只登记首次copy时点或null，全部20seed仍保留在每组主分析。

未来若重访移除实验，要另行固定政策和分母；可考虑以全部20seed为分母的预定触发政策，但必须明确未触发者及条件结果，不能默默删除。此处没有批准或启动该后续实验。
