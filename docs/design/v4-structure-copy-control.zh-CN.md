# 结构副本观察的真实物理受控检查

## 目的与边界

Study017–018的自然来源轨迹没有遗传双副本；合成快照测试不等于真实物理下的端到端阳性对照。本项只检验观察器能否识别按规则产生、但由人为初态和外部输入安排的结构重现。不把构造成功算作自然涌现、演化适应、功能繁殖或V4毕业，不扩展原400步研究。即使构造失败也保留固定全部案例，不调参直到成功。

## 固定三案例与输入

16×16周期世界，原始单位在(5,5)、(6,5)，material=0、program=(0,0,0,0)、energy=64；另在(12,12)放material=3、program=(3,3,3,3)、energy=64的孤立单位，使目标双成员组件不是全世界。其他格点为空。原始四份原料各放在(5,6)、(6,6)、(5,7)、(6,7)，其他格点原料0。

三个固定案例：原料4且exchange=False；相同初态与输入但exchange=True；原料全部0且exchange=False（无形成负对照）。其余capacity64、leak1、bond_cost1、threshold16、construction_cost4、copy_cost1、mutation_per_thousand0。每例恰32步，不根据中途结果延长或修改。

每步只在(5,5)、(6,5)、(5,7)、(6,7)提议输入8，其余提议0；空位提议照常被拒绝。方向默认：x=6的所有格点向西(1)，其他向东(0)；第1步仅两原目标单位位置改向南(2)，第2步仅(5,6)、(6,6)改向南(2)，第3步以后无覆盖。每位置每步突变票固定(999,0,1)，突变率0。所有票与初始原料/能量均由实验者指定，不是随机来源或演化程序。

意图是先形成连接的六成员条带，再让未直接供能的中间两成员在关闭交换时消耗殆尽，留下两个横向双成员材料组件；交换开启是否改变结局按实际记录报告。结构布置主要来自外部输入和方向票，这个检查不声称程序编码了形状或自主复制周期。

## 观察、核验与有限命题

使用原hereditary_growing.step，不修改物理。逐步保存完整输入、物理账本、身份/父链与final材料分区，再运行study017生产analyze与独立recount，分别比较全部32步四类计数、区间、最长。期望关闭交换有至少10步遗传双副本条件，零原料无形成；期望是否实现是输出而非静默改输入。交换开启无预设成功判据。

另一作者从单独写出的初态/票重新构建物理，使用exchange_branch_audit.physical_step及其独立audit/growing_audit规则；自行按形成/消解重建身份、材料分区和父链，核验全部96步、能量/质量、观察结果。绑定全部实际依赖、协议和两新脚本。独占data/v4-copy-control，60秒/32MiB，失败保留；三案例不得缩减。正式执行96新模拟步、0独立随机来源；工程测试运行另列，不混作新研究样本。

一条不依赖结果的有限命题：从一个n成员初始材料组件的n个初始祖先出发，单步不可能得到两个匹配的完整n成员纯祖源材料副本。每存活原成员最多形成一个孩子，新生当步不能再形成，故达到2n成员要求原成员全活且各生一个、全部2n均具有父材料。原组件连通仍保留，每个孩子与其原成员父相邻且同材料，全部2n仍连通，不能成为两个完整材料组件。此论证不排除多步中的消解、异材料中间后代或其他结构过程，不宣称任意步数不可能。

构造预期未实现与执行异常分开：阳性不足10步不提前跳过其他案例，全部可正常运行且通过物理核验的案例仍保留，统一报告expectations_met。真实执行/物理异常保留失败与部分结果，不编造剩余案例。
