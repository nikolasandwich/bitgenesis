# Study012 交换取舍的事后对应分析

已知主要结果为交换开启提高平均材料连续性而降低端点谱系存活。本补充使用全部40配对和全部共同初始组件，不运行新世界，不声称中介因果识别。

## 问题与固定观察

1. 在干预前合格的全部局部多成员组件中，交叉列出两分支持续闭合与谱系存活的四类对应（两者均是、仅开启、仅关闭、两者均否）。不依据干预结果改变资格。
2. 每分支每组件保留首次离开闭合多成员的状态（灭绝、碎裂、混合、闭合单例）；从该时刻保存快照和完整父链独立判定，不能拿端点状态替代首次失败状态。持续闭合记无失败。
3. 完整计入100步内归属出生/死亡，包括短命后代，分别报告原成员及后代死亡。核对末期人数=初始人数+出生−死亡，死亡身份与存活原成员一致。
4. 保留所有初始组件，汇总主要使用原study012局部多成员分母。保存每面板整数交叉表、按来源四锚点/条件五来源等权的四类比例。全世界/单例不丢失，但不与局部组件混算。
5. 原始物理事件读取与另一路身份集合差分重建出生死亡须一致；首次失败状态须独立用父链逐次回溯及组件集合验证。绑定完整study012索引、分支载荷和脚本哈希，异常留痕，输出独占；30分钟/128MiB软限额。

本补充描述“哪些起点发生何种对应差异”，不证明首次失败由某个具体生死事件或交换的单一中介造成。所有结果包括零值和不利方向都保留。
