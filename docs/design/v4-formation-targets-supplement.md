# Study013形成目标事后核查

本补充使用已完成的全部4,000配对、973,345条共同起点行动者。study013交叉表已知：仅关闭形成1,558次，其中开启时1,176次因目标占据受阻；仅开启形成186次。以下为结果启发的事后核查，不是新预注册因果试验，不新增模拟或独立来源。

对全部配对逐一保存所有形成不一致行动者（总数预期1,744，须由完整记录重算而非强行截取），记录双方同一方向目标、双方交互后行动者能量、阈值、目标交互后能量及是否消解、双方指向该目标且满足能量/空位/原料条件的候选行动者集合、转移gross_in、gross_out与net=gross_in−gross_out，逐项保存，不用净额代替总流出。独立重建形成前占据/原料：从共同历史起点和两分支interaction_units确定零能量消解，形成前raw=共同起点raw+该位置消解指示，然后检查全部起点行动者候选，不从终态占据倒推，因为终态可能已有新生替补。

固定核对：
- 开启occupied/关闭formed：目标原单元是否关闭消解而开启存活；报告符合/不符合全部数量，不预先要求机制必真。
- 开启energy/关闭formed与反向：行动者是否跨越形成阈值，并记录目标空位、原料及候选数的同步差异；不把跨阈值当成隔离中介。
- collision/formed两个方向：重建全部竞争者集合及对方额外竞争者，记录其能量、目标状态的差异。
- 全体行动者检查零能量集合的包含关系，报告新增/避免消解；按净接收/净输出/零净额分层，不只挑死亡与出生案例。
- 对全部非空位置，独立从转移列表累加净额，核对开启能量=关闭能量+净额、总净额0，以及每位置流出量不超过4*floor(关闭能量/8)。该上界来自四邻居同时扩散：每条流出最多floor(E/8)。E>0时流出最多E/2，因而交换不能把正能量变为0；E=0无输出，只可能被输入救活。这是当前固定规则的局部性质，不是一般交换定理。

按突变分组并保留全部10来源整数/精确每400步均值。主study013结论不改写；行动者总数及分类必须复原study013所有矩阵非对角formed行/列。对原料不足或消解等未出现的类别保留0，不省略可反驳项。

保存独占data/v4-study-013-targets目录、逐例records.jsonl、summary与metadata。输入绑定study013运行元数据/来源索引/独立凭据、全部配对文件和对应原始历史文件、协议/分析器；前后校验，失败留痕。另一路独立验证器复算全部配对与输出，不调用生产分类。工程反例覆盖救活目标阻止形成、能量跨阈值、竞争者改变、同一步死亡补位、同时收支且净额为零及E=1/7/8边界；正式结果后独立审查。
