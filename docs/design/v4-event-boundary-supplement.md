# Study011 局部人口事件与边界对应补充

用户已授权继续 study011 报告中的下一步。本补充为事后机制定位，不增加独立样本，不是新因果实验。已有26条非全世界事件窗口这一结果已知。

## 需求与边界

1. 读取全部20来源和全部400面板，保留初始多单元、合格、零事件及非全世界分母；从所有非全世界合格组件提取全部出生/死亡，不选择有利来源。
2. 在每个来源内部以事件类型、身份、原始事件时刻去重，保留每个时相/边界/锚点/组件引用。不同来源的相同数字身份不能合并，出生与死亡不能合并。
3. 对每个事件报告 contact、material、bond 的成员对应。出生以亲代所在的事件前组件为参照，死亡以死亡身份所在组件为参照。事件后取与原组件存活成员或新生身份相交的全部组件，保留成员列表、增减成员、后组件个数；这不是因果贡献分解。
4. contact/material 使用 interaction(t) 至 final(t)，几何与材料不因当步交互本身改变。bond 使用 interaction(t) 至 interaction(t+1)，明确包含下一步补给及交互，若无下一快照必须记缺失而不是零。
5. 绑定上游归档、原始载荷、观察和脚本哈希，输出目录独占，异常保存失败状态。运行软限额30分钟、128MiB，不覆盖上游。独立核对全部去重事件和引用及边界成员关系，再发表全部结果和解释限制。

## 验证与任务

- [ ] 实现事件去重及边界对应，先验证测试失败；覆盖出生、死亡分裂、同时合并、末端缺失及重复引用。
- [ ] 完整执行并独立复核，保存报告与精简可重算证据，提交并推送。

不修改模拟规则，不重复禁出生填空对照；本补充不能估计事件发生率或局部结构的无偏存活率。
