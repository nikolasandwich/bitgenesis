# 两历史人口路径：study015事后过程核查

study014和study015的完整终点已知：开启历史百步人数效应−4.50/−4.55，关闭历史+0.35/−1.35。此次对两研究全部160个已保存分支作过程账本，不新增模拟或随机来源。目标是看净人口差如何由形成和消解积累，不能将此事后描述称为隔离因果中介。

## 冻结范围与统计

固定种子112000–112004、突变0/100、历史开启/关闭、锚点100/200/300/400、当前交换开启/关闭。每分支保留t=0..100的全世界占据数、累计形成、累计消解、初态原成员仍存活数及分支中新生后仍存活数，不以组件资格或有利结局筛选。空世界计数0；失败不得变成统计缺失。

逐步恒等式：占据=初态占据+累计形成−累计消解，原成员存活+新生存活=占据。生产由物理事件与身份更新计数，独立路线由相邻活身份集合差分计数并对照父链/事件，覆盖同一步同位置死亡补位和不能复活。只读取保存记录，不调用模拟步进。

历史内先当前开启−关闭、再每来源四锚点等权、每突变五来源等权；历史差之差按共同来源/锚点先计算关闭历史效应减开启历史效应。两历史初态人数可以不同，不能直接将不同初态的绝对人口差当作当前交换效应；各历史内两分支初态须相同，因此两种差的计数恒等式仍成立。

输出全部160分支路径、两历史各40配对/10条件化来源/2条件路径及历史差之差40配对/10来源/2条件路径。正文固定t=1/10/25/50/100，全部十来源终点和各指标正/零/负配对数；完整100时点不充当独立样本，不选择事后峰值或删反例。每一历史百步世界人数及差之差须精确复原study015已核验汇总，包括当前开/关绝对值。
