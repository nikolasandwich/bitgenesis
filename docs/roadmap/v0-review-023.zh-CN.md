## 原始五种子复核观察

第1轮突变组各种子新增性状值数为199、224、193、176、164；实际改变遗传值的出生为598、696、578、585、598。无突变组这两项全部为零。所有十个世界中，创始个体的直接后代数最小值为0、最大值为4至12，亲子记录重数与保存的后代数字段逐个一致。

这些量区分了“产生变异”和“繁殖不相等”，但两者并存不自动证明变异导致优势。复核没有运行新的世界，也未增加实验计数。读取方式是：按parent_id重数验证offspring，逐条将子代genome与父代比较，计算全出生取值集减创始取值集，并在全部metrics行中查找首次population为0的时间。

## 现在能作出的研究决策

第22轮的突变处理配对净存活优势为+2；第23轮将早期抽样性状与真实祖先置于统一环境后，来源平均存活差为0。两个结论同时保留：本项目已建立可遗传变异与差异繁殖的最小世界，尚未获得本轮早期抽样性状平均性能改善的证据。

因此停止用新增V0运行次数作为阶段进展指标。保留V0作为冻结基准；新V0实验必须说明它能区分哪两种解释。当前唯一运行阶段仍为V0。下一步优先检查未来V1方案中信息输入、行动预算与祖先对照是否可辨识，并把缺失条件写清；设计检查不启动V1运行或更改已有V0语义。

[V1评估合同](../design/v1-evaluation-contract.md)要求分别检验信息影响行动、信息具有繁殖价值、进化增强信息依赖。三类证据目前都缺失，不能用V0的长期存活或新增移动概率代替。V2至V4及开放式进化也仍为路线图。

## 独立重算这份复核

在仓库根目录运行以下命令，输出路径必须尚不存在：

```console
python -I -S scripts/recheck_v0_graduation.py --expected docs/research/results/v0-graduation-recheck-023.json --output data/graduation-recheck.json
```

脚本只使用标准库，读取第1轮原始谱系与完整5001行指标，并检查冻结引擎的规范化哈希。新输出须与已提交复核报告完全一致；不调用模拟器，也不替代原始完整运行审计。该脚本在二十三轮固定归档之后提交；从归档重算时可使用当前脚本配合`--root`指向解压后的bitgenesis目录，`--expected`指向当前已提交报告。
