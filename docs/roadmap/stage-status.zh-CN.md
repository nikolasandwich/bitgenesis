# 当前阶段证据与尚未完成的标准

进入下一阶段原型不表示上一阶段已经取得预期科学结果。

| 阶段 | 已有证据或工具 | 尚未建立 |
| --- | --- | --- |
| V0 | 最小遗传、资源竞争、生死闭环及24轮实验记录 | 智能、记忆或开放式创新 |
| V1 | 可遗传控制器、感知干预和完整实验；首轮主要演化比较为阴性 | 相对真实祖先的信息利用收益改善 |
| V2 | 局部发育、成本与失败记录；遗传变化可延续，扰动可改变行为 | 发育编码的演化优势 |
| V3 | 双资源、来源归属与干预工具；两次试跑未过原繁殖门槛，机制研究结果已核验 | 稳定共存、演化分工、互利；干预分支动态的全面独立重建 |
| V4 | 局部连接、能量与材料账本、损伤恢复对照；局部遗传、真实祖先谱系；单独扩张和双祖先竞争已核验，有限条件下平均差为正 | 任意结构恢复、结构复制、群体遗传；跨环境稳健适应与可扩展遗传表示 |
| 后续开放式进化 | 既定研究问题和证据要求 | 持续功能创新的有界实验证据，更不能证明无限演化 |
