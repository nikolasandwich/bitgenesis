# 需求文档

## 引言与边界

研究者需要明确既定北向前缀之后撤除方向控制的条件效果，先证明终态和环境能连续承接，再按固定协议执行。纳入全部28个既定分支，沿用原人工初态、外部供能、物理和完整副本标准。此规格不修改旧研究，也不估计从未干预或自主生命出现；方法阶段不生成未来数据。

### 1. 完整来源和条件分母

**目标：** 保留全部既定分支，避免末端阳性选择。

1. When 研究准备续接, the Study047 system shall 验证全部28个043北向tick32完整终态、原始模板、移除历史、身份和祖系均可无物理重放承接，否则停止并报告缺失。
2. The Study047 system shall 保留100原索引、72原32步未触发N/A及10旧短窗标签，仅28个分支产生未来结果，并保留五编码全格及同seed相关性。
3. While 处于方法阶段, the Study047 system shall 仅核验来源与过去1–32环境/状态结构，保持0未来环境抽签、0新增或重放物理和0未来科学输出。

### 2. 连续环境、政策和固定窗口

**目标：** 比较同一已处理终态的继续与撤除。

1. When 两臂建立, the Study047 system shall 从同一tick32完整终态分别续用101/102北向掩码或撤除掩码，并共享同seed自然环境后缀、保持全部其他输入和规则。
2. When 恢复环境, the Study047 system shall 核验真实原始种子流与消费顺序的前32票、固定供能/突变票及运行时证据，在连续性不符时停止，不能用新seed替代。
3. The Study047 system shall 在任何未来票或结果读取前固定33–64的32步和工程/正式分开预算，禁止选窗、缩队列或提前停止掩盖失败。

### 3. 观察、指标和解释

**目标：** 维持已验证完整遗传副本和持续标准。

1. When 观察未来末态, the Study047 system shall 沿各编码原模板识别整个材料连接组件、完整程序及原祖系新副本，以实际至少2副本连续10未来步为主终点，保存完整计数、见证和撤除减继续配对差。
2. When 区间触达边界, the Study047 system shall 单列tick32诊断、未来左右删失和跨界观察长度，禁止用过去长度满足未来持续10标准，并区分原t0后出生与32后出生。
3. The Study047 system shall 保存每步全部事件、失败原因、身份/祖系及能量/材料账和全部阴性零项，以tick32为未来收支基线且不重复移除。
4. When 解释结果, the Study047 system shall 限定为既定北向前缀后的完整政策撤除效果，明确方向同时影响程序材料表达，并保留外部供能与人工初态的解释限制，不能升级自主出现或独立环境数。

### 4. 执行门槛与可复核性

**目标：** 方法、工程和正式结果有明确来源和失败证据。

1. The Study047 system shall 按方法、生产实现、独立核验实现、首E120005工程与独立审查、干净提交、正式完整队列的顺序执行，各路线遵守600秒/128MiB预算。
2. If 执行或收尾出现异常、来源变动或具体类型不符, then the Study047 system shall 保存失败epoch、进度、前后来源和已有输出hash并传播首异常，禁止覆盖或误记complete。
3. When 声明阶段完成, the Study047 system shall 提供对应当前版本的实际验证证据和独立审查，并保存可逐字节恢复的结果与执行来源；工程重复与正式队列不得混计。
