# V2 study002：遗传变化能够延续，尚未显示种群收益

20个世界全部完成3000步并通过完整集合核验、逐世界独立审计及配对初始状态检查。
10个独立来源各比较开启与关闭突变的世界。预登记的终点种群差
（开启减关闭）为9组零、1组负一，来源平均为 **−0.1个体**。
两组均9/10世界存活；来源84000的两组均灭绝，没有替换。

| 指标（每组10个世界） | 开启突变 | 关闭突变 |
| --- | ---: | ---: |
| 尝试构建的创始个体 | 320 | 320 |
| 成功构建的创始个体 | 38 | 38 |
| 创始空结构失败 | 282 | 282 |
| 后代构建尝试 | 58 | 58 |
| 成功出生后代 | 58 | 58 |
| 相对亲本基因发生改变的后代 | 6 | 0 |
| 其中继续留下后代的个体 | 2 | 0 |
| 最高代数（创始为0） | 3 | 3 |

6个基因改变的后代中，4个表达控制器与亲本不同，2个相同；
控制器权重变化仍不等于行为概率变化。来源84005的个体36和来源84006的
个体36分别留下1个成功后代。完整核验记录保留每个非创始个体与真实亲本、
创始祖先的关系、出生死亡时间及繁殖数，没有按结果挑选代表谱系。

这说明当前系统可以完成“遗传变化→有效发育→继续繁殖”的部分链条。
它没有证明改变后的个体更适应环境、更善于利用信息，或发育编码优于直接编码。
关闭突变组仍然存在创始基因之间的选择；两组差异不能单独分离选择与漂变。
10个来源是比较单位，58次出生不是58个独立进化实验。

空结构是明显的创始瓶颈，282/320个构建失败；两个实验组共享同一批初始状态，
不能把重复失败当作独立样本。3000步内最多3代、仅6次实际基因变化，
对长期演化的证据很有限。没有后代构建失败也是本次观察结果，不能推出其不可能发生。
