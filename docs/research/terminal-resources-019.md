# 第十九轮补充：灭绝时，世界还有食物吗？

**七次灭绝都有剩余食物。** 这是一项看过正式结果后的事后分析，读取既有逐步指标，
没有重新运行世界，也不增加独立种子。输入文件的 SHA-256 与完整指标核验一致。
全部四十个世界均检查：七个灭绝，三十三个在万步时仍存活。

每次灭绝前一步都只剩一个个体，个体能量合计为 1；下一步新增摄食为零、
基础消耗为 1、无出生，个体能量和人口都归零。根据未改动的 V0 行动顺序，
基础付款在移动和摄食之前，因此这个个体在到达摄食阶段前死亡。
这是由已核验总体指标结合规则作出的推断；前百步之外没有保存同等详细的个体终止记录。

## 能排除什么，不能排除什么

全世界食物为零不是这些终止事件的必要条件。表中同时给出前一步库存，
避免把死亡当步刚长出的食物误解成此前已存在的资源。

库存为正仍不等于个体能够及时取食。当前指标没有末期个体位置、局部地图或选中的移动目标，
不能计算距离、可达路径或此前受阻次数。“基础付款阶段死亡”描述最后一步如何结束，
也没有解释它为什么会只剩 1 点能量。它不是提高繁殖阈值改善存活的完整因果机制。

三十三个存活世界的灭绝时库存记为缺失，不记为零。本表条件于灭绝，
不应用来估计所有世界的平均库存或作存活与死亡群体的无偏因果比较。
完整输出保留四十个身份及删失状态。

## 下一步的取舍

先补齐位置与局部资源观测，再决定是否值得做资源重排干预。
允许穿越占据格会改变空间排斥；每步洗牌食物会改变环境时间结构；
免费移动和免费出生也会改变种群与随机路径。它们都不是单独关闭一个机制。
下一项观测应预先固定全部世界和窗口，验证不改变随机数、事件及原指标，
并同时记录资源总量与个体附近可摄食资源。旧轨迹重放仍只能算补充观测。
