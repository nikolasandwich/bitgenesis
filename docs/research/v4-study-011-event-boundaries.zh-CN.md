# Study011 补充：局部事件去重与边界对应

全部20个来源已检查。study011 的26条有事件的局部组件窗口，对应13次不同事件：6次出生、7次死亡，分布于7个来源。全部位于低输入250条件；高输入来源与无事件来源均保留，没有新增模拟或独立样本。

这13次事件的材料组件变化均很简单：出生为2人组件增至3人，死亡为3人组件减至2人。没有观察到材料组件在这些事件前后发生分裂、合并或引入额外身份。结果说明已见局部人口变化可以具体描述为小组件的增长、缩小；不能据此声称主动维持、结构复制或原成员完全更替。

## 选择与对应规则

这是在已知 study011 结果后的事后补充，见[冻结分析说明](../design/v4-event-boundary-supplement.md)，不是预注册的新验证。提取全部非全世界合格组件的出生、死亡记录，按来源、事件时刻、事件类型、身份去重，保留各时相/边界/锚点/组件引用。全部400面板的初始多单元、合格、零事件、全世界及局部事件计数随结果原样保存；没有把所选13次事件当作总体发生率的分母。

出生以亲代所在的事件前组件为参照，死亡以死亡身份所在组件为参照。事件后取与原组件成员或新生身份相交的全部组件，保存完整成员和增减身份。因此若同一步存在其他人口事件或合并，结果不会只留下目标事件。

contact/material 比较当步 interaction(t) 与 final(t)。bond 比较 interaction(t) 与 interaction(t+1)，中间包含下一步补给及交互；不能把连接差异归因于单一人口事件。缺失下一快照应记 null，本次13事件均有相应快照。

## 后续判断

本次证据没有显示需要引入更复杂生命机制来解释这些局部变化。下一项有区别性的候选问题是：局部能量交换是否帮助小组件在成员死亡后保持连接与谱系延续？任何正式干预都应从全部预定来源/锚点建立基线、对照分支，保留失败和零事件案例，不能只从这批按持续闭合结果筛选出的13次事件出发。

在登记前须先核实开关交换是否只改变预期的能量转移，保持连接扣费、出生规则及随机输入的配对含义，并明确主要指标是结构与谱系延续而非早期 study001/002 的整体连接或占据率。当前只是候选问题，尚未登记或启动该干预；现有生命判据未改变。
