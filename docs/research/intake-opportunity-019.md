# 邻格有食物，不等于本步会摄食

第十九轮所有个体的移动概率固定为 250/1000，移动扣费为零，基础消耗为 1。
在能够活过基础付款的条件下，个体有 75% 的概率不尝试移动；另外 25% 中均匀选择
四个相邻格。每一个方向的边际选择概率因此为 1/16，即 6.25%。

若脚下无食物，且有 k 个空闲含食邻格，本步正摄食概率为 k/16。
一个这样的邻格对应 6.25%，四个对应 25%。能量为 1 时，个体先死亡，摄食概率为零。
这解释了为什么观测到大量“附近有食物”的行动，并不要求随机移动个体频繁摄食。

## 一步期望的定义

令 C 为当前格可摄食量，即食物与摄食上限 8 的较小值。
对每个方向 i，若目标未占据，令 D_i 为该格可摄食量；若目标被占据，令 D_i=C，
因为移动失败后仍在原格摄食。若行动前能量大于 1：

E[摄食量 | 当前局部状态] = 3C/4 + (D_1 + D_2 + D_3 + D_4)/16。

把 C 与 D_i 分别替换为是否大于零的指示量，就得到正摄食概率。
当目标全部占据、原格有 8 点食物时，期望摄食为 8，而不是只计算未移动的 75%。

这里的期望是按策略规定的均匀随机抽取分布计算。若给定完整伪随机数状态，
下一次结果是确定的；本分析没有把两种条件混为一谈，也不沿一条替代轨迹继续推演。

## 对已记录窗口的应用

[输出](results/intake-opportunity-019.json)覆盖全部四十个世界、38,471 次局部行动。
每个世界保留一步策略期望的精确分数之和、实际摄食及正摄食行动数，
以及能够活过基础消耗且有空闲含食邻格的行动计数。输入与空间核验的文件校验值一致。

这些是同一批已实现局部状态上的描述。窗口按灭绝或万步终点对齐，具有结局选择，
不能将实际值与期望之差直接检验为“运气异常”，也不能把差值当作换策略后的存活效果。
未来策略会改变后来的位置、人口、资源和随机抽取；不能逐项替换本表就得到因果反事实。

此分析没有新增寻食行为，没有训练控制器，也没有产生 V1 证据。

```sh
python -I -S scripts/analyze_v0_intake_opportunity.py --output data/my-intake-opportunity
```

四个针对公式的测试覆盖单个食物邻格、基础死亡、全占据时原地摄食和全部空闲含食邻格。
分析会额外核对完整四十世界名单、原始配置文件校验值，以及移动扣费、基础消耗、摄食上限、地图尺寸和固定性状条件；不适用的配置会拒绝。输入约束加强后，四十个世界的数值结果与上一版完全一致。
