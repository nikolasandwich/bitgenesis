# V3未繁殖谱系：能量上限、空间接触与观察时间

重新核验全部40个世界，并为每个成功构建的个体重建终生能量、行动次数、
空资源接触、未用配额和最高繁殖前能量。所有终生能量恒等式通过。
这是一项事后轨迹分析，没有新增模拟，也不替换原1000步的失败选择结果。

## 一个可由规则证明的限制

来源87004在处理上限16时，唯一存活个体7的A分配值为5，故A/B配额为5/11。
关闭回收且初始B为0时，环境永远没有B，单次最多摄取5单位A，
向下取整后最多获得2单位能量。基础和决策费用共2，因此这个个体即使每次
遇到充足A也不能增加能量。它出生后的可用能量为534，低于1280繁殖门槛。
没有繁殖就没有后代突变；在当前规则和控制条件下，这不是增加补给就能解决的限制。

实际关闭回收的两档补给中，该个体终点能量452/472，1000次摄食均无正净收入。
开启回收后终点能量为1105/1153，仍未达到1280。这时“尚未繁殖”不能解释为
绝对不具备增能能力，也不能推断继续运行必然繁殖；后者需要另行定义观察窗口。

## 空间轨迹同样重要

来源87002、处理16、补给30、开启回收时，个体29有600/1000次摄食位置的A为空，
个体30有517/1000次。它们在两类资源饱和时理论可获7/8能量，但实际分别
只获1728/1954，总维持费用各2000。饱和能力上限不等于实际世界中的可用摄食量。
行动高度集中也只是观察结果，不能未经干预就断定是“错误策略”。

## 接下来追踪副产物来源

回收B可能被原释放者再次利用，也可能被其他个体摄取。当前总量记录无法直接
区分自我回收与跨个体利用，更不能把回收组的增能称为合作。
下一步从完整摄食事件离线重建B的来源分配，按明确的混合假设区分自身、同谱系
和其他谱系。标签只用于分析，不影响运行或提供奖励。由于原世界的B没有粒子身份，
来源归属是额外的记账约定，须报告其假设并检验不同约定的敏感性。
即使观察到跨个体摄取，仍需干预才能证明伙伴存在对繁殖有因果价值。
