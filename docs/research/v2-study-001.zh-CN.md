# V2 study001：基因变化、结构变化和行为变化并不等价

完整检查了100个随机父基因和2000个局部扰动版本，来自20个独立随机源，每源5个父基因。
**22/100个父基因能构建有效控制器；424对前后均有效的结构中，83对改变固定探针上的动作概率。**
这些是发育映射的敏感性结果，不是进化、适应性或发育编码优越性的证据。

| 前后有效性 | 扰动数 |
| --- | --- |
| 有效→有效 | 424 |
| 有效→无效 | 16 |
| 无效→有效 | 14 |
| 无效→无效 | 1546 |

全部2000个扰动中，98个因边界裁剪等原因保持基因不变，仍保留在原分母中。
260个改变输出权重，131个改变表达连接集合；这些结构计数包含有效性转换。
行为比较仅限424对均有效结构，83对的32状态平均总变差大于零，其余341对为零。
其余1576个扰动的行为差为缺失值，不记为零。固定探针未覆盖所有可能状态，
零差也不证明在所有环境中行为完全相同。

每个有效结构的同权重直接表达对照均通过独立重建，费用按登记填充相等。
这验证条件性对照的实现，不比较两种基因空间的进化能力。所有发育过程、
失败原因和有效性均独立重建；行为概率另用60个等概率并列票计算核验。

研究使用各坐标±1的对称扰动并保留裁剪重复，这不同于运行时部分坐标±10
的突变范围，不能把此次比例直接称为真实后代突变概率。五个父基因及其扰动
嵌套于一个来源，2000个扰动不是2000个独立进化实验；没有做显著性检验。
