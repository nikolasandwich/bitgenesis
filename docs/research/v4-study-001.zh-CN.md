# V4首轮活动研究：输入维持连接，主要指标未区分交换作用

20次运行各500步，全部通过独立动态核验、参数集合核验及60个固定窗口检查。
五个来源的四个对照条件共享初始单元和输入随机抽取次数。

| 条件 | 晚期251–500步至少一条连接的比例（五个来源） |
| --- | --- |
| 无输入、无交换 | 0、0、0、0、0 |
| 无输入、有交换 | 0、0、0、0、0 |
| 有输入、无交换 | 1、1、1、1、1 |
| 有输入、有交换 | 1、1、1、1、1 |

预登记主要指标中，输入效应在每个来源均为+1，交换效应均为0。
这是当前设置下受外部供能驱动的连接活动，不能称为自我维持、复制或演化。
零交换差也不证明交换没有作用：至少一条连接的指标在有输入组达到上限，
无法区分连接数量和具体结构的变化。

有输入且开启交换时，五个来源晚期平均连接数分别为73、84、83、64、73，
平均最大组件规模为10、9、7、5、6。无交换时有些连接数略低，完整数据保留
这些差异及早中期窗口，不用单一主要指标抹去过程差别。
材料标签和位置都固定，因此最大组件的几何可能性已经被初始化与亲和规则限制。

不再通过延长同类固定单元试验来寻找复制证据。下一步需要另行定义局部材料
转换或单元增减规则，并设计不依赖群体ID的结构识别与复制判据。
保留当前模型作为固定几何、受驱连接的基线，不将组件变化直接当作生命事件。
