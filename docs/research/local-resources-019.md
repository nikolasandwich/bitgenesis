# 第十九轮局部观测：食物就在邻格，为什么仍会死亡？

**七次灭绝的最后一个体，脚下都没有食物，但都有空闲且有食物的邻格。**
它们行动前只剩 1 点能量，先支付基础消耗后死亡，尚未进入移动和摄食阶段。
这说明最后一步不是被其他个体堵住所有相邻食物，也不只是世界远处尚有资源。
它仍没有说明此前如何降到 1 点能量，更没有证明任意感知策略能避免灭绝。

本分析按[预先固定的补充观测方案](../../experiments/v0/observation-019-local-resources.md)，
重放全部四十个世界，保存各自终点前二十个行动时刻、二十一个边界状态。
灭绝世界以首次灭绝为终点，存活世界以 10,000 步为终点；这是依结局对齐的描述，
不是同龄世界的无偏比较。重放 337,368 步，匹配 337,408 行原指标，
保留 840 个边界状态和 38,471 条局部观测，不增加独立种子或正式实验计数。

## 七次灭绝的最后一步

下表邻格顺序为东、西、南、北。全部最后个体的能量为 1、脚下食物为 0，
四个邻格均未被占据，繁殖阈值均为 40、移动扣费均为零。
数值是食物能量，记录于该个体基础付款前，已包含当步资源再生。

| 种子 | 出生扣费 | 灭绝步数 | 最后个体 ID | 四邻格食物能量（东 / 西 / 南 / 北） |
| --- | ---: | ---: | ---: | --- |
| 1600 | 0 | 136 | 218 | 4 / 0 / 4 / 0 |
| 1601 | 0 | 118 | 202 | 8 / 0 / 0 / 0 |
| 1605 | 0 | 2180 | 2183 | 16 / 0 / 8 / 0 |
| 1607 | 0 | 138 | 64 | 0 / 4 / 0 / 0 |
| 1601 | 4 | 244 | 204 | 4 / 0 / 8 / 0 |
| 1604 | 4 | 133 | 195 | 0 / 0 / 8 / 0 |
| 1605 | 4 | 4419 | 3930 | 20 / 4 / 24 / 0 |

这些是观察值，不是“只要移动就能活”的反事实：原规则中能量为 1 的个体已经没有机会执行移动。
若改成先吃后扣费，改变的是行动顺序；若更早有方向性移动，改变的是策略与后续轨迹。
这两种干预回答不同问题，当前都没有运行。

## 完整末期窗口

每个比例先在单个世界内计算，再给出该组最小值与最大值。
分母是该世界二十步内全部个体行动，包括进食前死亡。两个条件可以同时成立。
它们测量行动前位置附近的库存，不等同于最终摄食成功率。

| 阈值 | 出生扣费 | 观察终点状态 | 世界数 | 脚下有食物的行动比例 | 至少一个空闲邻格有食物的行动比例 |
| --- | ---: | --- | ---: | --- | --- |
| 40 | 0 | 灭绝 | 4 | 0.00%–10.00% | 83.72%–100.00% |
| 40 | 0 | 存活至万步 | 6 | 6.38%–14.95% | 73.49%–89.66% |
| 40 | 4 | 灭绝 | 3 | 0.00%–5.00% | 94.44%–100.00% |
| 40 | 4 | 存活至万步 | 7 | 6.61%–10.80% | 78.11%–97.19% |
| 160 | 0 | 灭绝 | 0 | 无样本 | 无样本 |
| 160 | 0 | 存活至万步 | 10 | 5.25%–9.84% | 81.36%–90.83% |
| 160 | 4 | 灭绝 | 0 | 无样本 | 无样本 |
| 160 | 4 | 存活至万步 | 10 | 6.08%–10.33% | 84.94%–97.45% |

灭绝组在绝大多数末期行动中存在空闲含食邻格，但这不保证个体会选择该方向，
也不保证它有足够能量走到摄食阶段。存活组同样常有相邻食物。
因此不能用“邻格有食物”单独解释存活差异；范围也不是置信区间，
38,471 次行动不是 38,471 个独立实验。

## 核验与限制

[边界核验](results/local-boundaries-019.json)检查食物、活体能量、占据地图和原指标；
[逐行动核验](results/local-actions-019.json)结合前后地图及摄食量推回本步资源增量，
再按保存的行动顺序还原移动、死亡、摄食和子代占位，核对每条局部记录及最终状态。
原重放进程正常完成；工程测试涵盖观测开关、完整状态与随机数不变，以及错误记录的拒绝。
159 项本地测试通过。

核验使用了记录的顺序、移动结果及子代边界位置，未独立重演每次随机选择。
原实验也没有保存这些末期行动路径，因此不能声称存在一份独立历史路径逐条佐证。
这里只覆盖二十步窗口，不能替代对早期扩张或全寿命摄食的解释。

```sh
python -I -S scripts/verify_v0_local_boundaries.py --output data/my-local-boundaries
python -I -S scripts/verify_v0_local_actions.py --boundaries-verification data/my-local-boundaries/summary.json --output data/my-local-actions
python -I -S scripts/summarize_v0_local_resources.py --output data/my-local-summary
```

前两条读取本地重放数据；第三条读取仓库已核验报告与本地重放记录。
[完整汇总](results/local-resources-019.json)保留全部四十个世界及输入校验值。
这项补充晚于十九轮固定下载包，原包不含新重放数据。[独立局部资源补充包](../design/local-resource-supplement.md)现已提供全部数据和五项复算；旧归档保持原范围。


## 后续加强：边界随机状态核验

新增[随机过程核验报告](results/local-random-019.json)覆盖全部四十个窗口、800 个行动时刻。
从每个保存的前边界随机状态出发，另行消耗资源再生、打乱顺序、移动决策与目标、
出生位置和固定基因下仍需消耗的突变决策，检查每步末尾随机状态完全一致。
它同时调用前述逐行动空间与能量检查。161 项本地测试通过。

```sh
python -S scripts/verify_v0_local_random_choices.py --boundaries-verification data/my-local-boundaries/summary.json --output data/my-local-random
```

此核验以保存的重放边界为条件，进一步验证内部随机过程一致性；原实验仍没有独立末期行动路径，
不能将其表述为历史观测的独立佐证。该新增脚本与报告晚于固定补充包，数据输入已在包内。
