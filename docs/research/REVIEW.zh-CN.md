# BitGenesis V0 验收入口

V0 已从骨架推进到可运行的最小达尔文世界。后续阶段尚未实现。

本地已生成 `data/review-v0.html`，双击可查看中文研究摘要，并进入世界回放和
谱系检查页。原始实验输出保存在 `data/campaign-001/` 到 `data/campaign-003/`；
这些大文件未推送，精简结果 CSV 和复现脚本已经进入仓库。

目前完成三轮、190 个实验、490,000 个时间步：

1. 有突变与无突变对照：都出现出生、死亡和谱系更替，但最后都只剩一个创始谱系。
2. 固定移动策略：少量移动的单一策略种群可比高移动种群维持更多个体。
3. 直接竞争与中性标签对照：低移动成本下高移动策略胜出；提高成本后通常反转。

这支持“世界规则会改变选择结果”，不支持“已经出现智能”或“开放式进化”。
个体、繁殖、遗传和资源规则依然是人为定义的；个体尚无食物感知和记忆。

验收建议：

- 在回放中拖动时间轴，切换基因/谱系着色，观察种群及资源变化。
- 在谱系页查个体 1640，点击父代 1618 和创始祖先 24，检查遗传与子代记录。
- 阅读三个实验报告中的对照、灭绝和局限，不只看存活的动画。
- 按 README 生成一个新实验，确认输出目录不可覆盖、记录来源清楚。

14 项测试和普通安装包运行已通过；每个正式实验时间步都检查能量收支与空间约束。
同种子重放和冻结版本指纹已测试，但没有宣称所有平台/解释器版本都逐位一致。

当前倾向：继续做 V0 鲁棒性和机制实验，保留旧规则，暂不急于添加神经网络。
完整检查点见 `ACCEPTANCE.md`；连续决策记录见 `LOG.md`。
