# BitGenesis V0 验收入口

V0 已从骨架推进到可运行的最小达尔文世界。后续阶段尚未实现。

最新研究已到十三轮、550 次执行、5,740,000 个计算时间步，完整材料见[研究索引](README.md)。
其中 20 次是同一批世界的延长复查，包含 200,000 步前缀重放，不增加独立种子样本。
第十三轮[基因取值长观察](campaign-013.md)已完成并加入十三轮页面；十二轮归档尚未包含。
有突变组五万步累计 340–371 个取值；新增数值不代表新增功能。
第十二轮[直接繁殖开销对照](campaign-012.md)已完成：体内储能、低阈值组即使免除直接出生扣费，
十次仍全部早期灭绝。当前页面和十二轮下载归档均已包含这一轮。
第十一轮[长观察](campaign-011.md)核对全部历史前缀后发现：原来 17 个存活世界都维持到
100,000 步，仍是有限时间证据。当前页面已包含这次延长复查，九轮历史归档尚未包含。
第十轮[繁殖阈值干预](campaign-010.md)发现：提高阈值后，体内储能组终点存活由 0/10
变为 7/10，食物组由 1/10 变为 10/10。它已加入当前页面，但不在九轮归档内。
第九轮的[等能量分配实验](campaign-009.md)发现：相同初始总能量下，环境食物组更易建立，
体内储能组十次全部早期灭绝。九轮草稿归档和当前页面均已包含这一轮。
第七轮发现：关闭突变、初始移动性状完全相同的种群，也有存活到 5000 步的案例。
这说明有限时间的种群维持不必依赖新变异，不表示无限期稳定。
第八轮进一步检验初始食物：空食物开局十次全灭；有初始食物的十次全部活到 500 步，
但仅三次活到 10000 步。初始资源帮助建立，没有保证后续维持。

本地当前验收入口为 `data/review-v0-13.html`，双击可查看中文研究摘要，并进入世界回放和
谱系检查页。原始实验输出保存在 `data/campaign-001/` 到 `data/campaign-013/`；
这些大文件未推送，精简结果 CSV 和复现脚本已经进入仓库。

视觉入口涵盖十三轮、550 次执行、5,740,000 个计算时间步（含上述重复前缀）：

1. 有突变与无突变对照：都出现出生、死亡和谱系更替，但最后都只剩一个创始谱系。
2. 固定移动策略：少量移动的单一策略种群可比高移动种群维持更多个体。
3. 直接竞争与中性标签对照：低移动成本下高移动策略胜出；提高成本后通常反转。
4. 资源条件：稀缺时灭绝，充足时持续繁殖，极充足时挤满世界后停止代际更替。
5. 世界规模：大世界在同样时长保留更多祖先标签，但保留比例并不更高；中性标签也会消失。
6. 稀缺资源：灭绝可能延迟到第 1,806 步；中间资源条件下，早期灭绝与活到观察终点并存。
7. 初始性状与突变：固定性状、无突变的种群也有持续到观察终点的案例。
8. 初始食物：帮助早期建立，但没有保证后续维持。
9. 能量分配：相同初始总量下，环境食物与体内储能出现不同的早期种群轨迹。
10. 繁殖阈值：提高阈值后两组存活增加，存活世界后期仍有出生和死亡。

11. 延长观察：同一批世界中，17 个存活者都维持到十万步，最终均只剩一个创始谱系。

12. 直接繁殖开销：免除出生扣费没有消除储能低阈值组的早期失败。

13. 基因取值长观察：累计出现的新数值与当前活体多样性不同，也不等于新增功能。

重建十三轮页面使用 `python scripts/build_v0_review.py --campaigns 13`，需要完整本地数据。
默认构建范围仍为八轮，以保持既有打包流程；输出不可覆盖，重建时可另选 `--output`。

另有一次精确突变校准：边界裁剪造成向区间内部的单代平均变化，不是单向偏爱高移动。
这是数学枚举，不计入上述实验数和时间步数。

这支持“世界规则会改变选择结果”，不支持“已经出现智能”或“开放式进化”。
个体、繁殖、遗传和资源规则依然是人为定义的；个体尚无食物感知和记忆。

验收建议：

- 在回放中拖动时间轴，切换基因/谱系着色，观察种群及资源变化。
- 在谱系页查个体 1640，点击父代 1618 和创始祖先 24，检查遗传与子代记录。
- 阅读十二轮实验报告中的对照、灭绝和局限，不只看存活的动画。
- 按 README 生成一个新实验，确认输出目录不可覆盖、记录来源清楚。
