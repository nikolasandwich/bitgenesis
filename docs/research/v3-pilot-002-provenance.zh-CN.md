# V3副产物来源：自我回收占多数，也存在跨谱系摄取

在再次完整核验40个世界后，对每次实际保留的B释放附加释放者标签，离线追踪摄取。
世界运行和摄取总量不变。比较“最早释放的先被摄取”和“最新释放的先被摄取”
两种记账约定；两者均逐次匹配库存，并与最终库存和审计中的总摄取量一致。
新释放的B在本次摄食完成后才进入标签池，溢出耗散不进入池中。

| B摄取单位归属（全部40个世界合计） | 最早优先 | 最新优先 |
| --- | ---: | ---: |
| 同一个体自我回收 | 70,257 | 75,010 |
| 同创始谱系的其他个体 | 13,060 | 11,149 |
| 其他创始谱系 | 37,233 | 34,391 |
| 合计 | 120,550 | 120,550 |

20个开启回收的世界在两种约定下均有跨谱系摄取，20个关闭回收的世界均无B摄取。
这是这批轨迹的描述性总量；高摄取世界权重更大，不能当作40个独立来源的统计估计。
实际独立来源为5个，各种设置共享来源。

多数B被归属于自我回收，说明此前回收开关的效果不能整体归为个体间互利。
跨谱系摄取量也不等于代谢所得能量：B的转化收益有逐次整数取整，表中只统计底物单位。
创始谱系相同不代表同一物种，不同也不等于生态分工。

原世界没有粒子身份，先后摄取约定是额外的解释层。两个结果是敏感性示例，
并非所有可能混合方式的严格上下界。释放者死亡后B仍可能留在环境中；本结果
也不能证明释放者与摄取者在同一时间共存，更不能证明伙伴持续存在提高繁殖。

下一步为伙伴移除及资源补偿设计有明确能量对照的机制实验，区分自我回收、
环境遗留资源和活跃伙伴影响。保留随机祖先试跑的失败结果，不把人为固定的
机制实验混同为已演化出合作或稳定生态。
