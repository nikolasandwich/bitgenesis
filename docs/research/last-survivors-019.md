# 七个最后存活个体：末尾二十步的能量与行动

**六个个体在最后二十步从未移动受阻，另一个只受阻一次；这七个个体都没有繁殖。**
它们的窗口初始能量加摄食恰好为 20，全部用于二十次基础消耗，最终归零。
因此，持续的移动受阻或该个体在此窗口内的繁殖分割，并不是这些末期衰退的共同过程。
这不排除此前的拥挤、繁殖或其他个体的影响。

这是看过局部资源结果后的**事后个案分析**：选择第十九轮每次灭绝的最后一个体，
共七个；三十三个观察终点仍存活的世界没有对应“最后存活个体”，明确排除。
不把这些个案视为随机个体样本，也不据此估计某种策略的总体效应。

“窗口内无”仅指这二十步没有摄食，不表示一生没有吃过。
移动成功也不等于找到食物；基因 250 仅给出每次符合行动条件时的随机移动概率，
不读取邻格食物。个体可能不移动，也可能随机走向无食物的格子。

[先前局部观测](local-resources-019.md)已经确认，七个最后死亡时刻均有空闲含食邻格，
但基础付款发生在移动与摄食之前。这里向前追溯了同一个体二十步，
并没有修改行动顺序或试验另一个策略。

## 这对后续问题的约束

先区分群体衰退与最后个体耗尽。七个末期轨迹不能代替早期群体史，
也不能说明较高繁殖阈值的好处通过哪条机制产生。

此时再重复“取消一次费用是否救活世界”的大网格，区分力有限。
更有价值的问题是：在生理参数和付款顺序完全相同的条件下，遗传控制器是否能利用
食物信息改变行动并获得可重复的优势。那属于未来 V1 的实验，不能用本报告提前宣告成功，
也不能通过给 V0 写死“走向食物”来替进化完成任务。V1 目前仍只保留设计。

## 复算与证据范围

```sh
python -I -S scripts/analyze_v0_last_survivors.py --output data/my-last-survivors
```

[完整输出](results/last-survivors-019.json)保存 140 条按时间排列的能量与行动记录、
全部排除身份和源文件校验值。所有输入与此前逐行动核验报告一致，
每条能量恒等式及相邻时刻能量连续性均检查通过。
此分析没有增加模拟执行或独立种子。

本分析晚于固定局部资源补充包；该包已含所需原始记录，但未含本次新增脚本与报告。
使用当前主分支脚本配合[补充包数据](../design/local-resource-supplement.md)即可复算，旧包保持原内容。
