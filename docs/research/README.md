## 证据能说明什么

| 已观察到 | 支持的有限结论 | 仍不能据此声称 |
| --- | --- | --- |
| 移动成本改变后，直接竞争优势反转 | 选择结果依赖所设计的环境和成本 | 有普适的最优移动策略 |
| 能维持更多个体的单一性状，未必赢得混合竞争 | 种群数量与相对繁殖成功是不同观测量 | 种群最大就是适应最好 |
| 中性标签也逐渐消失，大世界保留更多绝对标签 | 谱系数量受有限世界和观察时长影响 | 颜色或祖先标签就是物种 |
| 极充足资源下，满员后停止出生与死亡 | 当前无衰老规则允许代际停滞 | 活着或保留多条谱系就是持续创新 |
| 有的种群在千步后才灭绝 | 短窗口存活不能证明长期稳定 | 活到终点就是永久存活 |
| 无突变、无初始移动性状差异的种群也能活到 5000 步 | 此条件下的有限时存活不需要产生新性状 | 已经发生新适应、学习或智能 |
| 有初始食物时全部建立，但不少种群在后续灭绝 | 建立成功与长期维持要分别观察 | 开局活下来就一定会持续繁殖 |
| 同为 7040 初始总能量，食物组更易建立，体内储能组早期全灭 | 初始能量的分配方式影响本模型中的结果 | 已独立证明灭绝由某个单一机制导致 |
| 提高繁殖阈值后，两种分配组的终点存活均增加 | 储能组早期失败依赖繁殖参数 | 已进化出更好的繁殖策略，或存在普适最优阈值 |
| 同一批 17 个存活世界维持到 100,000 步 | 原队列的已观察维持时间延长 | 新增了 20 个独立样本，或已经证明永久稳定 |

以上均为本模型的有限实验结果。没有食物感知、记忆、神经控制器或生命自发起源。
生物个体、遗传、行动含义和繁殖过程仍是人为规定的。后续阶段的研究问题见
[路线图](../roadmap/README.md)与[V1 设计提案](../design/v1-proposal.md)。
前十轮结果对后续控制器实验的具体约束见[V1 实验设计](../design/v1-experiment-design.md)，
目前仍只有文档，没有新增运行阶段。

## 繁殖机制的下一项证据

[第十二轮](campaign-012.md)已执行预先声明的分配 × 阈值 × 直接开销对照。
体内储能、低阈值条件下，开销为 0 和 4 的两组都十次全灭；零直接开销组的早期出生
反而更多。这排除了“正的直接出生扣费是这些早期失败的必要条件”这一解释，仍未把
能量分割、基础消耗、移动或局部获取资源中的某一项确定为唯一原因。

高阈值的体内储能组，两种开销下都存活 9/10；食物组都存活 10/10。降低直接开销
没有消除本样本中的阈值差异，也不保证改善存活。详细的三个观察窗口和描述性差异见报告。
零直接开销不等于繁殖没有后续成本：子代仍分走亲代能量、消耗资源并占据空间。

当前十二轮页面已包含第十二轮摘要，新十二轮下载归档也包含其原始记录。V0 基本验收证据见[检查点](ACCEPTANCE.md)。
若后续进入控制器阶段，仍需[匹配生理参数并干预感觉输入](../design/v1-experiment-design.md)，
检验信息是否改变繁殖结果；这些生理实验不构成 V1 已成功的证据。

## 怎样复核

1. 打开对应协议，确认种子、配置、干预、观察窗口与排除规则。
2. 查看报告记录的源代码提交。精确历史复现使用该提交；当前代码的兼容性由冻结规则测试约束。
3. 按协议运行到新的 `data/` 目录。旧数据不可覆盖，运行状态须以实际进程和完成记录核实。
4. 完整生命周期运行使用 `bitgenesis audit`；仅指标实验使用对应复算工具，不能声称验证了未保存的事件。

数据一致性检查与模型科学解释分开。随机种子重复、能量守恒、文件哈希都很重要，
但不证明生物真实性。检查的具体范围、残留限制与命令见各报告。

工具与决策：[验收检查点](ACCEPTANCE.md) · [断点恢复](../design/checkpoints.md) ·
[兼容性政策](../design/experiments.md) · [连续决策日志](LOG.md)。
