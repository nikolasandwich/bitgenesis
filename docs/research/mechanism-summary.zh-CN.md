# 二十二轮之后：哪些过程已看清，哪些原因仍未确定

**V0 已能稳定记录遗传、繁殖、资源竞争和灭绝；目前还没有感知、记忆或智能证据。**
提高繁殖阈值能改变这批世界的早期过程和有限期存活，但尚未识别传递该影响的唯一机制。
资源总量、个体摄食、能量转移、容量损失和存活是不同观测量，不能互相替代。

当前正式清单为二十二轮、1,124 次执行、10,440,000 个计算时间步，包含 24 次延长复查和
212,000 步前缀重放。这是工作量，不是独立样本数。后来的个体、空间和库存回放另行记账。
完整计数见[研究索引](README.md)和[清单核对](results/campaign-inventory-verification.json)。

## 证据按问题组织

| 问题 | 已有证据 | 能支持的判断与限制 |
| --- | --- | --- |
| 早期总摄食更多是否保证存活？ | [十七轮](campaign-017.md)原阈值成片组前百步总摄食高于分散组；[个体分析](individual-intake-017.md)显示较多摄食主要来自后来出生的个体 | 总摄食不能替代创始群体覆盖或长期存活；摄食集中也未被确定为唯一原因 |
| 出生空间短缺和移动受阻是否相同？ | 十七轮前百步仅一个世界有两次符合能量条件却无出生空位；[移动记录](figures/campaign-017-movement-outcomes.png)则显示大量目标受阻 | 两种空间约束必须分别衡量；记录受阻不证明受阻造成灭绝 |
| 取消直接成本能否保证存活？ | [十八轮](campaign-018.md)零移动扣费仍有成片低阈值灭绝；[十九轮](campaign-019.md)移动和出生均免费时仍有 4/10 灭绝 | 正的直接扣费不是这些失败的必要条件。免费繁殖仍转移亲代能量并增加后续基础需求 |
| 最后死亡是否因为全局食物耗尽？ | [十九轮末期账目](terminal-resources-019.md)的七次灭绝均有剩余食物 | 排除这些末期事件的全局资源耗尽解释，不证明个体能够及时获得食物 |
| 最后一个体是否被邻居挡住食物？ | [末期局部记录](local-resources-019.md)中，七个最后个体均有空闲含食邻格，能量为一，先死于基础付款 | 最后时刻的邻格占据不能解释这些死亡；此前拥挤、摄食不足及其他过程仍未排除 |
| 最后个体还在不断繁殖消耗能量吗？ | [末二十步轨迹](last-survivors-019.md)中七个最后个体均无繁殖，六个无移动受阻、一个有一次受阻 | 这是按结局选择的个体窗口，不是种群整个衰退期的因果解释 |
| 名义平均补给相同是否足以匹配环境？ | [二十轮](campaign-020.md)低阈值三组存活为 3/10、1/10、3/10，稀疏大量与基准存在两个方向的配对反例 | 频率与批量的联合干预改变了实际输入和后续轨迹；不能称为纯波动效应或普遍优劣排序 |
| 终点补给总量是否都是给活种群的？ | [窗口拆分](supply-windows-020.md)中，23 个灭绝世界有 51.50%–79.67% 的新增资源发生在灭绝之后 | 原预定固定终点总量必须保留，同时明确它包含空世界供给；不应据此估计活种群摄食效率 |
| 更少容量截断是否一定更利于存活？ | [库存回放](renewal-stocks-020.md)中，同补给方式的高阈值组前百步截断比例范围更高，却全部存活至万步 | 截断比例不能充当存活排序；库存与消耗共同变化，尚无独立截断干预 |
| 增大容量是否能一致改善存活？ | [二十一轮](campaign-021.md)在相同初始食物下配对容量24/96，低阈值三种补给的净存活优势为 +1、−2、−4，每种都有仅小容量存活的种子 | 未支持三组均为正的预登记预测，并反驳本队列的逐种子单调改善；不能推论大容量普遍有害或独立容量损耗中介 |
| 相同性状祖先开启突变是否改善存活？ | [二十二轮](campaign-022.md)20个配对中，突变组10/20存活，无突变组8/20；仅突变存活6对、仅无突变存活4对 | 有限队列净优势+2符合方向预测，但有反例，未检验显著性或后代相对祖先的可遗传性能改善 |

各实验的种子、费用和地图条件不同。上述反例只作用于对应设计，不能合并成一个新的总体效应。
十个种子的多个配对处理、同一世界的数千次行动，也不能都当成独立重复。
万步存活是右删失，不是永久稳定。

## 容量规则已经解释了什么

[精确校准](renewal-capacity-020.md)给出相同格子库存下的平均新增量：
补给概率 × min(批量, 剩余容量)。三种方案的名义平均均为 0.06，
但只剩一个单位容量时，平均实际新增分别为 0.06、0.015、0.005。
这个条件平均排序由规则直接决定，经过全部 75,000 个离散抽签情况核对。

[库存观测](renewal-stocks-020.md)进一步测到了真实前百步地图上的实际截断与条件期望损失。
实际截断比例以实际抽中的未截断资源为分母；期望损失比例以名义期望总量为分母。
它们都已核对，但不是同一统计量。将另一补给方案的公式代入现有地图，也不等于运行了
另一种环境：未来库存、摄食、繁殖和随机调用都会改变。

因此我们已经从“可能有容量损失”推进到“规则上可以精确计算，实际轨迹中可以核验”，
但没有推进到“容量损失独立造成了某些灭绝”。

## 为什么认为这些记录可用

工程测试比较有观测和普通引擎的完整状态、事件、谱系及随机状态；新增观察不消耗世界随机数。
库存观测使用单独复制的随机状态，重建补给抽签而不修改世界。

历史回放对齐原指标；独立核验再检查个体能量与生命周期，或地图、库存直方图与补给抽签。
二十轮库存回放覆盖六十个世界、6,000 个补充时间步、6,144,000 次补给抽签，
6,060 行边界指标与原实验一致。核验范围见[完整报告](results/renewal-stocks-020-verification.json)。

这些证据仍有边界：原实验并未独立保存全部历史个体路径和每步随机状态。指标一致本身不等于
唯一历史路径证明；不同观察工具所能重建的内容也不同。更强的末期局部行动核验只适用于其
明确保存的窗口，不能自动推广到全部实验。

## 变异出现与适应性改善的区别

第22轮全部祖先基因相同，关闭突变的所有出生继续保持250；开启突变后可以产生新移动概率。完整个体历史已经核对，但产生新数值、改变群体平均性状和改善处理组存活是不同层次的结果。

如果要检验后代是否获得可遗传的性能改善，需要在另行预定的统一环境中比较后代与实际祖先，并明确灭绝世界无终点后代如何计入。不能只挑幸存世界里表现最好的个体，也不能把突变尝试数等同于改变性状的出生数。当前未登记这一后续实验。

## 下一步怎样选择

目前优先保留一个可复现、语义不变的 V0 基线。更多同类参数扫描只有在检验一个明确的新预测时
才值得运行，不能以实验数量代替问题进展。

若要研究容量损失的因果作用，需先设计独立对照：提高容量会同时改变储存及后续摄食，
重分配溢出资源会改变空间分布，补足损失则可能引入依赖当前状态的供给反馈。
这些都不是天然的“只去掉损失”。应在运行前写出干预改变的过程、竞争解释和可证伪预测，
并保持全队列、固定窗口和失败记录。第二十一轮已按预登记进行了有限容量干预并报告反例；它仍未隔离纯损耗中介。当前不因预测未获支持而自动增加容量扫描。

若范围扩展到 V1，核心问题应是信息是否改变行为、是否带来繁殖价值、进化是否增强这种价值。
必须匹配感官对照的生理成本、初始地图及繁殖条件，使用真实祖先、随机控制器、屏蔽和打乱感知
等对照，并保留独立验收种子。当前仍是[设计](../design/v1-evaluation-contract.md)，没有 V1 运行结果。
