# V3机制研究：移除伙伴未降低本次所测终点，补回效果有限

全部5个预登记来源通过完整集合核验。4个来源具有可比较目标，共12个分支；
88003没有合适目标，保留为空值。共同前缀为300步，分支继续500步。
下表只统计被移除目标之外的谱系，不能与整个世界种群数混淆。

| 来源 | 其他谱系终点数量：对照/移除/补回 | 新出生数：对照/移除/补回 | 补回接受/拒绝的B |
| --- | --- | --- | --- |
| 88000 | 6 / 8 / 8 | 4 / 6 / 6 | 3320 / 813 |
| 88001 | 2 / 2 / 2 | 0 / 0 / 0 | 4054 / 706 |
| 88002 | 1 / 1 / 1 | 0 / 0 / 0 | 209 / 459 |
| 88003 | 无法比较 | 无法比较 | 无法比较 |
| 88004 | 5 / 5 / 6 | 1 / 1 / 2 | 3399 / 176 |

四个可比较来源中，移除相对对照的种群/新出生数差均为[2,0,0,0]；
补回相对移除均为[0,0,0,1]。描述性平均分别为+0.5和+0.25，
条件是具有可比较目标；空值未记为零，没有显著性或普遍性结论。

本次没有观察到“移除使其他谱系终点数量或新出生数下降”的预期模式。
这不证明伙伴无作用：移除同时减少A竞争、释放空间并改变行动顺序，
还保留过去已沉积的B。补回有一步延迟，且大量请求因容量上限未被接受。
因此补回不能复原原世界，也不能把88004的一个额外后代直接称为合作。

## 核验范围

独立重建了共同前缀、仅依据前缀的目标选择、对照释放计划和干预边界。
所有共同起点、分支配置、完整事件、终点及结果均核对；分支动态使用原引擎重放，
不是另一套独立世界实现。初始化和突变抽取的独立随机重放仍有限制。
这些限制随完整核验报告保留，不用“全绿”代替科学证据。

V3已经具备双资源交互、来源分析和干预工具，但尚未证明稳定共存、演化分工
或互利。两次生存性试跑的失败门槛保持不变。接下来整理阶段证据，并可按自主
研究授权启动V4局部单元原型；这不宣告V3科学问题已解决，也不通过继续挑参数
寻找正结果来替代机制理解。
