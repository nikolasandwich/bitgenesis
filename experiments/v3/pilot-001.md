# V3 pilot001: viability before ecological interpretation

Preregister before launching any of these worlds. Run20 cases: source seeds
86000..86004 crossed with A renewal_per_thousand15/30 and recycling1/0.
Use v3-world-1, ecological encoding, intact sensing,16x16 sites,32 random founder
attempts, initial A12/B0, capacity24 per substrate, initial energy640,
birth threshold1280, and all other V3 Config defaults. Run1000 ticks including
after extinction; no replacement seeds, founder filtering or outcome-based restart.

Record every construction attempt and its failure reason, both substrate grids,
actor transfers, lineage, source/configuration hashes and summaries. Require the
composed independent audit for every world and complete-grid verification before
interpretation. Keep paired recycling arms' initial states identical. Subsequent
resource trajectories and interactions can differ.

Report each world's survival, extinction tick, successful births, maximum
generation, founder/offspring failure reasons and resource flows. A recycling-on
cell is usable for a later population study if at least4/5 worlds are alive at
tick1000 and each surviving world produced at least one successful nonfounder.
Select renewal15 if usable, else30 if usable, else no selected setting. Report
recycling-off outcomes regardless; they do not affect that calibration choice.

The removal control changes retained environmental energy, not just partner
identity. This pilot does not demonstrate cross-feeding benefits, stable niches,
cooperation or evolved differentiation. The next ecological study needs explicit
trait-frequency windows and additional controls that address energy retention.

Freeze clean launch revision and protocol hash. Bound each run by256000 actor
records and check4GiB total output between runs (one bounded run may overshoot).
Stop incomplete on an execution/audit error or storage threshold, retaining all
outputs. Preserve all null results and do not tune this registered cohort later.
